# Zelar – Aplicativo de Apoio ao Idoso

O **Zelar** é um aplicativo Android desenvolvido com o objetivo de promover a inclusão digital e proporcionar mais autonomia e segurança para pessoas idosas.

O projeto busca oferecer uma interface simples, acessível e intuitiva, reunindo funcionalidades úteis para auxiliar na organização da rotina e no acesso rápido a informações importantes.

## Funcionalidades

- **Lembretes de medicamentos:** auxilia no controle dos horários de medicação.
- **Agenda de compromissos:** permite organizar consultas e outros compromissos.
- **Contatos importantes:** facilita o acesso a familiares e pessoas de confiança.
- **Emergência:** disponibiliza acesso rápido a números de emergência.

## Tecnologias utilizadas

- React Native
- JavaScript
- Expo
- AsyncStorage
- Expo Notifications

## Armazenamento de dados

O aplicativo utiliza armazenamento local no dispositivo. Os dados não são sincronizados com a nuvem e podem ser perdidos caso o aplicativo seja desinstalado.

## Como executar o projeto

1. Instale o Node.js.
2. Clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Instale as dependências:

```bash
npm install
```

5. Inicie o Expo:

```bash
npx expo start
```

6. Abra o aplicativo pelo Expo Go ou execute em um ambiente Android compatível.

## Objetivo do projeto

O Zelar foi desenvolvido como parte de um projeto de extensão acadêmica, relacionado à disciplina de Programação para Dispositivos Móveis em Android.

Seu propósito é utilizar a tecnologia como ferramenta de inclusão digital, autonomia e apoio à qualidade de vida da população idosa.
